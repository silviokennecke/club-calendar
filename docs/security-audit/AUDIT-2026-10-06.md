## INFO / hardening

- **I2 `.htaccess`**: `Options -Indexes -MultiViews` is intentionally not set (breaks managed hosting with restrictive AllowOverride); keep sourcemaps off (frontend agent saw none in the build). [BACKEND-F13]
- **I3 Misc backend**: fixtures password `password123` (dev only); `PruneUnverifiedUsersCommand` not scheduled; refresh token is hand-rolled HS256 JWT with standard base64 rather than base64url; `OidcProvider::parseIdToken` doesn't validate signature/iss/aud/nonce (OK: token from token endpoint over TLS) and no PKCE; local `config/jwt/public.pem` is 0666; 404-vs-403 existence oracle on IDs (UUIDv7, not guessable). [BACKEND-F14, AUTH-Info, AUTHZ-F8/F9]
- **I4 Frontend**: route guards client-side only (backend enforces); IDs placed into API paths without `encodeURIComponent` (`useCalendarData.ts:48`, `api.ts:178`); OAuth provider id into href unencoded; legacy `accessToken` storage key still read. [FRONTEND-F7/F9, F4]
- **I5 Dependencies**: CI runs no `npm audit --omit=dev` (and no `composer audit`); dev tooling lags (`vitest`/`tinypool` critical advisories, fix = vitest 5.0.3, a major bump). Dev-only, not in the production bundle. [FRONTEND-F5]

## Scanner results (verified by lead)

- **composer audit --locked:** clean (0 advisories).
- **semgrep (php, security-audit, ts, react, owasp-top-ten):** 0 findings.
- **gitleaks:** no genuine findings (rotated Mapbox tokens).
- **trivy:** the guzzle 7.12.3 hits (CVE-2026-69246 etc.) come from a **stale `.deploy/build/` lockfile copy**; the real `backend/composer.lock` pins guzzle **7.15.5** → false positive. Also covers `.deploy/` build artifacts — exclude that dir in future scans. The `jwt/private.pem` "secret" is gitignored (local only). Dockerfile misconfigs not reviewed.
- **npm audit (27: 3 critical, 17 high, 6 moderate, 1 low), remaining part:** critical `vitest`, `tinypool` (dev test runner; fix = vitest 5.0.3, major bump) and critical `proxy-addr` 2.0.7 (transitive, via tooling; Windows-only advisory; not used by the app runtime). Recommendation: bump vitest, add `npm audit --omit=dev` + `composer audit` to CI.
