# Your first event

:::note
You need the Editor or Admin role for this. Viewers can only look at events.
:::

A new event starts as a **draft** that only your club can see. It appears in the feeds only once you publish it.

## Create an event

1. Open the **Calendar**.
2. Start in one of these ways:
   - Click **Create event** at the top.
   - Double-click a day in the month grid. The date is already filled in.
   - Click a day, then click **Create event on this day** in the day panel.
   - On a smartphone, tap the round **Create event** button.
3. Choose **New event**. With **From template** you start from a [template](help:organize/templates) instead, also for whole event series.
4. Fill in the form and click **Save event**.

![New event form with the basic data filled in](shot:first-event-form)

## The fields

**Basics**

- **Name** (required): once you type at least three letters, the app suggests matching templates and takes over their settings.
- **All day**: start and end time are then dropped.
- **Start date** and **Start time** (required).
- **End date**: only needed for multi-day events.
- **End time**: required for events with a time. It must not be before the start time.

**Location**

Pick an existing location. If it is missing, use **Create new location** to add one right away. If the location has a position, you see it on the map. More under [Locations](help:organize/locations).

**Badges, extras and audiences**

Here you assign [badges](help:organize/properties), [extras](help:organize/features) and [audiences](help:organize/target-groups) to the event. If you pick no audience, the event applies to everyone. If something is missing, you can create it right here.

**Note**

Optional, up to 2000 characters. All members of the calendar see the note. For published events it is also visible in the feeds.

**Status**

- **Draft**: only your club sees the event.
- **Published**: the event appears in the feeds.

A new event starts as a draft. Switch it to **Published** when it is ready.

## Tips

- If a required field is missing, the form shows what is still needed and **Save event** stays disabled.
- If you close the window without saving, the app asks first. An unsaved draft is kept on this device; next time you can choose **Restore**.
- You cannot create events in an archived calendar.
