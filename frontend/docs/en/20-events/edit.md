# Edit, move and delete events

:::note
You need the Editor or Admin role for this. Viewers can only look at the event (**View event**).
:::

## Edit an event

1. Click the event in the calendar or in the [event list](help:events/event-list).
2. Change the details in the **Edit event** window. The fields are the same as when [creating](help:events/first-event).
3. Click **Save event**.

At the top of the window you see whether the event is a **Draft** or **Published**. Changes to a published event are visible in the feeds immediately.

The calendar search ([Search and filter](help:events/search-filter)) opens the events it finds in this same window.

## Move an event

On a computer, drag an event in the month grid onto another day. The time stays the same; for multi-day events the whole period moves along.

A short message “Event moved to …” appears with **Undo**. Use it to bring the event back.

On a touch screen, press and hold the event, then drag. On a smartphone and in the week or list view, move an event by opening it and changing the **Start date**.

## Delete an event

1. Open the event.
2. Click **Delete event** at the bottom left.
3. Confirm with **Delete event**.

:::warning
A deleted event disappears from the calendar and from all feeds. This cannot be undone. If you only want to hide it for now, set it to **Draft**.
:::

## Events in a series

If the event belongs to an [event series](help:organize/series), the window says **Part of an event series**. When saving or deleting, the app asks whether the change applies to:

- **Only this event**
- **All events of the series**: all events take over only the details you changed. A changed date applies to the opened event only.

You change the series rule with **Change series**, see [event series](help:organize/series).

## Archived calendars

In an archived calendar, events are read-only: you can view them but not change, move or delete them.
