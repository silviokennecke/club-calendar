# The event list

The event list shows all events of the calendar at a glance, including far-away ones. Open it through **All events** in the sidebar, **Events** on a smartphone, or **List** at the top of the calendar.

## What you see

Events are grouped by month in a table with the columns **Name**, **Date**, **Time**, **Location**, **Audiences**, **Extras** and **Status**. An icon after the name shows badges that have an emoji; “Recurring” marks events of a series. Below the title you see how many events the calendar holds. At first 100 events are shown; use **show more** to load more.

Click **Name**, **Date**, **Location** or **Status** to sort the list.

![Event list with the All, Published and Draft tabs](shot:event-list-overview)

## Status: draft or published

Every event has a status:

- **Draft**: only your club sees it.
- **Published**: it appears in the [feeds](help:publishing/feeds).

The tabs **All**, **Published** and **Draft** filter by it. The number on a tab tells you how many events are in it. Search and audience filter affect the numbers.

## Open an event

Click an event in the **Name** column. It opens above the list; search, tab and filters are kept when you close it. How to change it is explained under [Edit events](help:events/edit).

## Search and filter

Above the table you search the name with **Search events…** and filter by audience. **Reset filters** clears the audience filters. More under [Search and filter](help:events/search-filter).

## Create new events

Editors and admins see **Create event** at the top. The menu next to it offers **From template** and **Import events**. See [Your first event](help:events/first-event).

## Select several events

Editors and admins have a checkbox in front of every event. When you select events, a bar appears at the bottom with bulk actions, such as publishing or deleting. Details under [Bulk actions](help:organize/bulk).

## When the list is empty

- **No events yet**: create the first event or import an ICS file.
- **No results for …**: check the spelling or reset the search.
- **Nothing published yet** or **No drafts**: use the offered button to switch to the other tab.

## Export and archived calendars

With **Export events** you save the events as a file, see [Export events](help:organize/export). In an archived calendar the list is read-only.
