# Delete a club

:::note
Only **Admins** can do this. Everyone else does not see the section.
:::

:::warning
Deleting a club cannot be undone.
:::

## What is lost

- the club itself
- all calendars with all their events
- all feeds (their addresses stop working)
- all templates
- access for all members

Members' accounts remain. They can still sign in and work in other clubs.

## How to delete the club

1. Open **Manage club** in the sidebar and the **General** tab.
2. In the **Danger zone**, click **Delete club**.
3. The dialog shows how many calendars, events and feeds will be deleted.
4. To confirm, type the club's name exactly (**Type the club name to confirm**).
5. Click **Delete club**.

Afterwards you land in the club picker.

![Delete club confirmation dialog](shot:delete-club-confirm)

:::tip
Only need to get rid of one calendar? [Archive or delete the calendar](help:settings/calendars) instead. If you just want to leave yourself, do so under [Members](help:team/members).
:::
