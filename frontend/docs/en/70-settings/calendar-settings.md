# Calendar settings

Here you change the name and time zone of the calendar you are working in.

:::note
Only **Admins** can change these. Everyone else can only view them. For an archived calendar everything is locked until it is restored, see [Managing calendars](help:settings/calendars).
:::

1. Open **Settings** in the sidebar and then the **General** tab.
2. Change the **Calendar name**. It appears in the calendar picker and in subscriptions.
3. Set the time zone (see below).
4. Click **Save settings**.

![Calendar settings, General tab](shot:calendar-settings-general)

## Time zone

By default **Use the club's time zone** is on, and the club's time zone is shown below it. That fits almost every calendar.

Only if the events take place somewhere with a different time zone, turn the toggle off and pick the right one under **Time zone of this calendar**. The events of this calendar are then shown in that time zone.

As a check, the page shows the current time in the selected time zone: "Current time in …". If it does not match the clock at that place, the wrong time zone is selected.

:::tip
How times are displayed (for example the 24-hour format) is a personal setting in your profile, not per calendar. See [Personal preferences](help:settings/preferences).
:::

## Duplicate, archive, delete

These actions are not here but under **Manage club**. A link at the end of the page takes you there. See [Managing calendars](help:settings/calendars).
