# Target groups

:::note
Editors and admins can create, change and delete target groups. Viewers can only see them.
:::

Target groups (called "audiences" in some places of the interface) say who an event is for, e.g. "Youth". Visitors can filter the calendar by them, and subscriptions can be limited to groups. Target groups belong to the whole club and apply in all calendars.

## Where do I find them?

Sidebar, under **Club** choose **Places and audiences**, then the **Target groups** tab.

## Create and edit

1. Under **Add a new audience**, enter a **Name**, e.g. "Youth".
2. Choose **Create audience**.

To rename, choose "edit" on an entry. The change applies to all calendars of the club.

## Delete

Choose "delete" on an entry and confirm with **Delete audience**. The group is removed from all calendars of the club: the link disappears from events and templates, and feeds that had selected this group lose it from their selection. The dialog first shows the numbers.

## Use it in an event

In the event's section "Properties, features and audiences", pick one or more under **Audiences**. Without a selection the event is for everyone. If one is missing, create it there with **Create new audience**.
