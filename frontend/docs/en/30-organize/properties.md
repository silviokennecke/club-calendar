# Badges

:::note
Editors and admins can create, change and delete badges. Viewers can only see them.
:::

Badges have a symbol (emoji), e.g. "Costume". They appear on the event in the calendar. They belong to a single calendar.

## Where do I find them?

Sidebar, **Settings**, **Badges** tab.

## Create and edit

1. Under **Add a new badge**, enter a **Name**, e.g. "Costume".
2. Optionally choose a **Symbol (optional)**.
3. Choose **Create badge**.

To change name or symbol, choose "edit" on an entry, then **Save change**. Names must be unique.

![Settings, Badges tab with form and list](shot:properties-list)

## Delete

Choose "delete" on an entry and confirm with **Delete badge**. The badge is removed from all events and templates; the events themselves stay. The dialog tells you the numbers first.

## Use it in an event

In the event's section "Badges, extras and audiences", pick **Badges**. If one is missing, create it right there with **Create new badge**.

:::tip
Duplicating a calendar copies its badges.
:::
