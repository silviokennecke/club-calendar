# Properties

:::note
Editors and admins can create, change and delete properties. Viewers can only see them.
:::

Properties are characteristics with a symbol (emoji), e.g. "Costume". They appear on the event in the calendar. They belong to a single calendar.

## Where do I find them?

Sidebar, **Settings**, **Properties** tab.

## Create and edit

1. Under **Add a new property**, enter a **Name**, e.g. "Costume".
2. Optionally choose a **Symbol (optional)**.
3. Choose **Create property**.

To change name or symbol, choose "edit" on an entry, then **Save change**. Names must be unique.

![Settings, Properties tab with form and list](shot:properties-list)

## Delete

Choose "delete" on an entry and confirm with **Delete property**. The property is removed from all events and templates; the events themselves stay. The dialog tells you the numbers first.

## Use it in an event

In the event's section "Properties, features and audiences", pick **Properties**. If one is missing, create it right there with **Create new property**.

:::tip
Duplicating a calendar copies its properties.
:::
