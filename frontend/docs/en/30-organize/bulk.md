# Change several events at once

Instead of opening each event, select several and change them in one step.

:::note
You need the Editor or Admin role for this. Viewers don't see the checkboxes.
:::

## How to do it

1. Open **All events**.
2. Tick the events you want on the left. The box in the header row selects all filtered events. Narrow down the list first with [search and filters](help:events/search-filter).
3. The **Bulk actions** bar appears at the bottom with the number of selected events.
4. Choose an action.

![Event list with selected events and the bulk actions bar](shot:bulk-bar)

## The actions

- **Publish**: the events become visible in the feeds right away.
- **Mark as draft**: the events disappear from the feeds and are visible only to your club.
- **Assign**: pick target groups, properties and features and click **Add … assignments**. They are added to the events; existing assignments are kept. You can't remove assignments this way; edit the single event for that.
- **Delete**: after a confirmation the events are deleted permanently. They also disappear from all feeds, and this cannot be undone.
- **Clear selection**: resets the selection without changing anything.

:::tip
After publishing or marking as draft you can take the change back with **Undo**.
:::

A bulk action applies fully or not at all. If something fails, no event is changed.

For an [event series](help:organize/series), a bulk action affects exactly the events you selected, not the whole series.
