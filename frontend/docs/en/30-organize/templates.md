# Templates

:::note
Editors and admins can create, change and delete templates. Viewers can only look at them.
:::

A template is a preset for an event, for example your weekly training. You use it to create events or a [series](help:organize/series) in a few clicks. Templates belong to one calendar.

## Where do I find them?

In the sidebar under **Set up calendar**, choose **Templates**. On a phone it is under **More**.

## Create a template

1. Choose **Create template**.
2. Enter a **Name**, e.g. "Air rifle training".
3. Optionally set a **Start time** and **End time**. Without both times, events are all-day. By default the club's time zone applies.
4. Optionally choose a **Default place**, badges, extras and audiences. Without an audience, events apply to everyone.
5. Optionally add a **Note**. Events take it over, and you can change it per event.
6. Choose **Save template**.

![The "New template" form with filled fields](shot:templates-form)

## Edit and delete

In the template list choose **Edit**. Changes apply to new events only; events already created stay unchanged. **Delete template** removes a template. Events already created from it also stay, and the dialog tells you how many there are.

## Use a template for an event

- In the list, choose **Event from template** next to a template.
- Or choose **From template** when creating an event, then pick the template. It takes over times, location and audiences and can also create series.
- Or type the name of a new event: from 3 letters on, the app suggests matching templates and applies their settings.

You can still adjust everything in the event. New events start as drafts.

:::note
In an archived calendar, templates can be viewed but not changed.
:::
