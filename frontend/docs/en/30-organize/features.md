# Features

:::note
Editors and admins can create, change and delete features. Viewers can only see them.
:::

Features are optional extras at an event, e.g. "Bonus shooting". You pick them when creating an event. Unlike [properties](help:organize/properties), they have no symbol. They belong to a single calendar.

## Where do I find them?

Sidebar, **Settings**, **Features** tab.

## Create and edit

1. Under **Add a new feature**, enter a **Name**.
2. Choose **Create feature**.

To rename, choose "edit" on an entry, then **Save change**. Names must be unique.

## Delete

Choose "delete" on an entry and confirm with **Delete feature**. The link is removed from all events and templates; the events stay. The dialog first shows how many are affected.

## Use it in an event

In the event's section "Properties, features and audiences", pick **Features**. If one is missing, create it right there with **Create new feature**. Templates can contain features too.
