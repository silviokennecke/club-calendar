# Extras

:::note
Editors and admins can create, change and delete extras. Viewers can only see them.
:::

Extras are optional additions to an event, e.g. "Bonus shooting". You pick them when creating an event. Unlike [badges](help:organize/properties), they have no symbol. They belong to a single calendar.

## Where do I find them?

Sidebar, **Settings**, **Extras** tab.

## Create and edit

1. Under **Add a new extra**, enter a **Name**.
2. Choose **Create extra**.

To rename, choose "edit" on an entry, then **Save change**. Names must be unique.

## Delete

Choose "delete" on an entry and confirm with **Delete extra**. The link is removed from all events and templates; the events stay. The dialog first shows how many are affected.

## Use it in an event

In the event's section "Badges, extras and audiences", pick **Extras**. If one is missing, create it right there with **Create new extra**. Templates can contain extras too.
