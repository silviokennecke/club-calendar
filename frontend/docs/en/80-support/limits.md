# Limits

To keep everything fast there are generous upper limits. In everyday club life you will rarely reach them. If you do, the message "Limit reached" appears; delete entries you no longer need.

## Per account, club and calendar

| What                           | Limit  |
| ------------------------------ | ------ |
| Clubs per account              | 50     |
| Calendars per club             | 100    |
| Members per club               | 500    |
| Open invitations per club      | 200    |
| Events per calendar            | 20,000 |
| Locations per club             | 2,000  |
| Audiences per club             | 500    |
| Feeds per club                 | 50     |
| Badges per calendar            | 500    |
| Extras per calendar            | 500    |
| Holiday calendars per calendar | 20     |
| Connected AI apps per account  | 20     |

## For a single action

| Action                                 | Limit                        |
| -------------------------------------- | ---------------------------- |
| Import                                 | at most 5,000 events at once |
| Bulk action (publish, delete ...)      | at most 5,000 events         |
| Event series                           | at most 366 events           |
| Events from a template on several days | at most 366 days             |
| Time span of an event query            | at most about 5 years        |

## Invitations

- An invitation is valid for 7 days and can be re-sent at any time (after one minute at the earliest).
- You can only send a limited number of invitations per day; too many gives "Too many invitations in a short time".

## Subscription address (calendar subscription)

A feed's subscription address does not contain every event of all time, but the events of the last 6 months and the next 24 months. The feed's web page and exports are not affected. See [Subscribe to a calendar](help:publishing/subscribe).
