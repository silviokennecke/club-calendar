# Roles in a club

Everyone in a club has one of four roles: **Member**, **Viewer**, **Editor** or **Admin**. The roles build on each other: an admin can do everything an editor can, an editor everything a viewer can, and a viewer everything a member can.

A **Member** only belongs to the club. Members do not see the club calendar itself. They read the events through their own subscription, see [My club](help:getting-started/my-club).

| Task                                                        | Member | Viewer | Editor | Admin |
| ----------------------------------------------------------- | :----: | :----: | :----: | :---: |
| Read events through the own subscription                    |  yes   |  yes   |  yes   |  yes  |
| View calendar and events                                    |   no   |  yes   |  yes   |  yes  |
| Create, change and delete events, series, templates, import |   no   |   no   |  yes   |  yes  |
| Manage locations, badges, extras, audiences, holidays       |   no   |   no   |  yes   |  yes  |
| View feeds                                                  |   no   |   no   |  yes   |  yes  |
| Create, change and delete feeds                             |   no   |   no   |   no   |  yes  |
| Create, archive and duplicate calendars                     |   no   |   no   |   no   |  yes  |
| Manage members and invitations, change roles                |   no   |   no   |   no   |  yes  |
| Change club settings, delete the club                       |   no   |   no   |   no   |  yes  |

:::note
You can tell you are a viewer by a notice: "Your role in this club only allows viewing." Viewers also do not see **Import events** and **Publish**, so they cannot see private feed links either.
:::

## Getting a different role

Admins choose the role when they invite you and can change it later under **Manage club** on the **Members** tab. A club never has no admin: the last admin can only give up the role once another member is admin. More under [Members](help:team/members).
