# Team

Ein Verein besteht aus seinen Mitgliedern. Wer welche Rechte hat, hängt von der Rolle ab (siehe [Rollen](help:getting-started/roles)). Neue Mitglieder kommen nur über eine Einladung dazu, die sie selbst annehmen.

- [Mitglieder](help:team/members): Liste ansehen, Rollen ändern, Mitglieder entfernen, den Verein verlassen.
- [Einladungen](help:team/invitations): Personen per E-Mail einladen und eine Einladung annehmen.
