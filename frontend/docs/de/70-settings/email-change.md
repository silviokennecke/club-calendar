# E-Mail-Adresse ändern

Mit deiner E-Mail-Adresse meldest du dich an, und an sie gehen Mitteilungen.

:::note
Dafür brauchst du ein Passwort. Wenn du dich nur über einen Anbieter anmeldest, lege zuerst ein [Passwort](help:settings/password) fest.
:::

## So geht's

1. Öffne dein [Profil](help:settings/profile), Bereich **Name und E-Mail-Adresse**.
2. Gib die **Neue E-Mail-Adresse** und dein **Aktuelles Passwort** ein. Das Passwort wird auf deinem Gerät geprüft und nie an den Server gesendet.
3. Klicke auf **Bestätigungslink senden**.
4. Öffne den Link in der E-Mail, die an die **neue** Adresse geht. Er ist 24 Stunden gültig.

Erst nach dem Klick auf den Link ändert sich deine Adresse. Bis dahin steht im Profil **Neue Adresse wartet auf Bestätigung**. Dort kannst du mit **Änderung verwerfen** abbrechen.

## Was danach passiert

- Du wirst überall abgemeldet und meldest dich mit der neuen Adresse neu an.
- Eine Benachrichtigung geht an die alte Adresse, damit niemand deine Adresse unbemerkt ändert. Bereits beim Beantragen geht eine Mitteilung an die aktuelle Adresse.

:::tip
Kommt keine E-Mail an, gehört die neue Adresse vielleicht schon zu einem anderen Konto.
:::
