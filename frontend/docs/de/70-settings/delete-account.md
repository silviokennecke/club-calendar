# Konto löschen

Du kannst dein Konto jederzeit löschen. Das geht nicht rückgängig.

## So geht's

1. Öffne dein [Profil](help:settings/profile) und gehe zum **Gefahrenbereich**.
2. Klicke auf **Konto löschen**.
3. Bestätige:
   - Mit Passwort: gib bei **Zur Bestätigung dein Passwort** dein Passwort ein. Es wird auf deinem Gerät geprüft und nie an den Server gesendet, siehe [Passwort](help:settings/password#so-sicher-ist-dein-passwort).
   - Ohne Passwort (nur Anbieter oder Passkey): klicke auf **Code senden**. Du bekommst einen 6-stelligen Code per E-Mail und gibst ihn bei **Bestätigungscode** ein. Er ist mindestens 10 Minuten gültig.
4. Klicke auf **Konto löschen**.

## Was gelöscht wird

Dein Konto, deine Passkeys und verknüpften Anmeldungen. Du wirst abgemeldet.

## Wann es nicht geht

:::warning
Solange du das einzige Mitglied eines Vereins bist, kannst du dein Konto nicht löschen. Lösche zuerst den Verein oder lade jemanden ein.
:::

:::warning
Bist du der einzige Admin eines Vereins mit weiteren Mitgliedern, mache zuerst jemand anderen zum Admin oder lösche den Verein.
:::

Zu viele Fehlversuche sperren die Bestätigung kurz. Warte dann eine Weile.
