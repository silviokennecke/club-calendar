# Grenzen und Limits

Damit alles schnell bleibt, gibt es großzügige Obergrenzen. Im normalen Vereinsalltag stößt du kaum darauf. Erreichst du eine, erscheint die Meldung „Limit erreicht“; lösche dann nicht mehr benötigte Einträge.

## Pro Konto, Verein und Kalender

| Was                            | Grenze |
| ------------------------------ | ------ |
| Vereine pro Konto              | 50     |
| Kalender pro Verein            | 100    |
| Mitglieder pro Verein          | 500    |
| Offene Einladungen pro Verein  | 200    |
| Termine pro Kalender           | 20.000 |
| Orte pro Verein                | 2.000  |
| Zielgruppen pro Verein         | 500    |
| Feeds pro Verein               | 50     |
| Besonderheiten pro Kalender    | 500    |
| Zusatzangebote pro Kalender    | 500    |
| Feiertagskalender pro Kalender | 20     |
| Verbundene KI-Apps pro Konto   | 20     |

## Bei einer einzelnen Aktion

| Aktion                                    | Grenze                             |
| ----------------------------------------- | ---------------------------------- |
| Import                                    | höchstens 5.000 Termine auf einmal |
| Sammelaktion (Veröffentlichen, Löschen …) | höchstens 5.000 Termine            |
| Terminserie                               | höchstens 366 Termine              |
| Termine aus Vorlage an mehreren Tagen     | höchstens 366 Tage                 |
| Zeitraum einer Terminabfrage              | höchstens etwa 5 Jahre             |

## Einladungen

- Eine Einladung ist 7 Tage gültig und kann jederzeit erneut gesendet werden (frühestens nach einer Minute).
- Du kannst pro Tag nur eine begrenzte Zahl von Einladungen verschicken; bei zu vielen kommt „Zu viele Einladungen in kurzer Zeit“.

## Abo-Adresse (Kalender-Abo)

Die Abo-Adresse eines Feeds enthält nicht alle Termine aller Zeiten, sondern die Termine der letzten 6 Monate und der nächsten 24 Monate. Die Webseite des Feeds und der Export sind davon nicht betroffen. Siehe [Kalender abonnieren](help:publishing/subscribe).
